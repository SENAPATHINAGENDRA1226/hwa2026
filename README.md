# Hack With Avanthi 2026

create a aebsite

Design and develop a premium, futuristic, highly animated website for **HACK WITH AVANTHI 2026**, a two-day technical hackathon organized by DLIDES CLUB at Avanthi Institute of Engineering & Technology.

VISUAL THEME: AI NEURAL UNIVERSE.

Create an immersive AI-inspired digital environment with a deep black and dark navy background, glowing cyan and violet colors, interconnected neural networks, floating particles, and futuristic typography.

HERO SECTION:
- Full-screen immersive hero section.
- Large heading: HACK WITH AVANTHI 2026.
- Tagline: "Where Intelligence Meets Innovation."
- Create a large animated 3D neural network sphere in the center or right side.
- Display interconnected glowing nodes with continuously moving connections.
- Add subtle particle movement in the background.
- Include Register Now and Explore Event buttons.
- Add a live countdown timer.

ABOUT SECTION:
- Introduce the hackathon using futuristic glass cards.
- Animate headings and content as the visitor scrolls.
- Show event details, date, venue and duration.

HACKATHON THEMES:
Display nine technology categories using interactive cards with AI-inspired animated icons.

TIMELINE:
Create a futuristic timeline with glowing connecting lines and animated milestones.

PRIZES:
Display prize categories using elegant glowing cards and animated prize counters.

REGISTRATION:
Create a modern registration section with a glowing call-to-action button.

ANIMATION REQUIREMENTS:
- Smooth scroll animations.
- Mouse-responsive particle effects.
- 3D neural network animation.
- Animated glowing connections.
- Text reveal animations.
- Smooth section transitions.

TECH STACK:
React, TypeScript, Tailwind CSS, Three.js or React Three Fiber, GSAP and Framer Motion.

IMPORTANT:
Make the design visually impressive but maintain excellent readability, responsiveness and performance. Use optimized animations and provide a mobile-friendly experience.

The final website should feel like entering an advanced artificial intelligence universe.

## Development

To run the project locally, install dependencies and start the dev server:

```sh
npm install
npm run dev
```
